### 1. GitHub Copilot代码审查将默认改为组织付费，企业需检查预算策略

- **状态：** new
- **类别：** AI开发者工具 / 企业计费
- **来源与热度信号：** GitHub 11月25日官方Changelog；受影响组织数量未核实。
- **发布时间：** 官方标注2026年11月25日，精确北京时间未核实。
- **一句话摘要：** 自2026年12月30日起，未主动设置Copilot代码审查计费方式的Business和Enterprise组织，将默认由仓库所属组织承担符合条件的审查费用。
- **为什么现在值得看：** 随着编码Agent和自动PR审查的使用频率提高，默认计费主体变化可能直接增加企业AI支出。
- **与现有方案的关键差异：** 此前未配置计费策略时，使用成员个人Copilot额度；变更后默认使用组织付费额度。已明确选择Member或Organization的组织不受影响。未启用AI Credits付费用量、存在计费锁定等情况也有例外。
- **使用门槛与适合谁：** Copilot Business及Enterprise管理员。希望维持原计费方式的组织，应在生效前进入Copilot策略设置，明确选择Member。
- **价格或许可证：** 本次调整的是默认计费主体，不是宣布单价上涨。实际新增费用取决于审查频率及AI Credits消耗量，未核实。
- **证据标签：** 一手来源确认
- **原始链接：** [GitHub官方计费变更公告](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/)
