### 2. GitHub Code Quality上传代码覆盖率时开始拒绝非Cobertura格式

- **状态：** new
- **类别：** CI/CD / 代码质量
- **来源与热度信号：** GitHub 11月23日Changelog；受影响工作流数量未核实。
- **发布时间：** 官方日期2026年11月23日，精确北京时间未核实。
- **一句话摘要：** `upload-code-coverage` Action现在会在报告不是Cobertura XML时直接失败，而不是表面上传成功却不显示PR覆盖率。
- **为什么现在值得看：** 现有CI可能开始显式失败；这也能揭露此前未被注意的无效覆盖率上传。

- **使用门槛与适合谁：** 已启用GitHub Code Quality的Team或Enterprise Cloud仓库；检查测试框架输出格式，必要时转换为Cobertura XML。GitHub Enterprise Server暂不支持。
