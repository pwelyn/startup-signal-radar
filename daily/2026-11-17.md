### 1. Qwen4-Max正式提供按量API；独立评测显示质量尚可但任务延迟偏高

- **状态：** new（11月16日正式版上线；11月11日已存在仅限Token Plan的预览版）。
- **类别：** AI模型 / 多模态Agent
- **来源与热度信号：** Hacker News 11月16日榜单第1，852分、470条评论（读取时快照）；真实API采用量未核实。
- **发布时间：** 2026年11月16日，具体北京时间未核实。
- **一句话摘要：** 阿里云上线 `qwen4-max`，支持文本、图像、视频输入和文本输出、工具调用及结构化输出，标称100万Token上下文。
- **为什么现在值得看：** 从预览订阅渠道转为可按量调用，适合将长上下文和Agent任务纳入真实成本、延迟对照；不应仅因旗舰定位而迁移。
- **与现有方案的关键差异：** 官方支持OpenAI与Anthropic兼容接口，推理深度可配置；当前仅API可用，未发布Max权重。模型总参数约2.4T、激活参数约71B的说法来自发布方及媒体转述，本次未取得公开权重核验。
- **使用门槛与适合谁：** 需要阿里云Model Studio账号及API额度；新加坡等区域可用。不能自行部署Max；官方明确不支持微调、批处理或模型部署。量化、显存要求不适用API版本。
- **价格或许可证：** 新加坡区域每百万输入Token 1.50美元、输出4.50美元；北京区域1.413/4.24美元，实际区域计费不同。闭源专有模型，权重许可证不适用。
- **独立验证：**
  - **厂商自报：** 相比Qwen3.8-Max，部分任务减少约50% Token、平均任务成本降低逾60%；未独立复现。
  - **LMArena：** 暂无本次核实的同版本结果。
  - **Artificial Analysis：** Intelligence Index 43，任务成本约3.27美元；评测页面显示任务耗时33.2分钟、输出速度53 Token/s，属于其比较样本中的较慢档。AA显示984K可用上下文，与厂商100万标称值口径不同；AA页面对部分指标存在缓存版本差异，需以实时页为准。
  - **社区实测：** HN与Reddit讨论活跃，但缺乏可复核的受控同任务实测。
- **证据标签：** 一手来源确认（上线、规格、区域价格）；性能优势仅为厂商声明，独立评测不支持“客观第一”。

### 2. GitHub AI Scan新增一次启动最多20个仓库扫描

- **状态：** update（相较11月14日报道的API配置能力，新增实际批量启动扫描的入口）。
- **类别：** 开发者安全 / AI代码扫描
- **来源与热度信号：** GitHub 11月16日官方Changelog；使用量、检出率与误报率未核实。
- **发布时间：** 2026年11月16日，具体北京时间未核实。
- **一句话摘要：** GitHub在公开预览中支持一次启动最多20个仓库的AI Scan，结果进入组织代码扫描待处理列表。
- **为什么现在值得看：** 11月13日的API更新主要解决批量配置开关；这次进一步解决管理员对多个仓库真正发起扫描的操作成本。
- **与现有方案的关键差异：** AI Scan可补充CodeQL未覆盖语言或额外发现，但并未提供独立证据证明检出率更高；扫描默认分支，不等于覆盖全部分支与运行时风险。
- **使用门槛与适合谁：** GitHub.com及具数据驻留的Enterprise Cloud；组织级设置启用后可选择仓库，或从组织扫描告警页发起。无需Copilot许可证，但需相应安全功能权限。
- **价格或许可证：** 单次扫描消耗GitHub Code Security AI credits；单仓库费用未核实。
- **证据标签：** 一手来源确认

### 3. GitHub Copilot停止支持三款旧模型，企业需核查固定模型配置

- **状态：** new（11月16日实际执行此前公布的弃用计划）。
- **类别：** AI开发者工具 / 模型生命周期
- **来源与热度信号：** GitHub 11月16日官方Changelog；受影响账户数未核实。
- **发布时间：** 2026年11月16日，具体北京时间未核实。
- **一句话摘要：** GitHub Copilot弃用Claude Opus 4.8、Claude Opus 5及GPT-5.6 Terra，建议迁移至Claude Opus 5.5、GPT-6.1 Sol或GPT-6 Luna。
- **为什么现在值得看：** 固定模型ID的内部文档、Agent流程和组织策略可能失效或产生行为变化，需要检查回归测试和审批。
- **与现有方案的关键差异：** 属于Copilot渠道的模型生命周期变更，不意味着原厂API同步下线；Claude Opus 4.8对部分年度个人订阅者仍有例外，Claude Opus 5仍可能用于已授权的拒绝回退路径。
- **使用门槛与适合谁：** Copilot Business/Enterprise管理员应检查模型策略和默认启用规则；显式禁用替代模型的组织需手动配置。
- **价格或许可证：** 新模型的具体用量价格未核实。
- **证据标签：** 一手来源确认
- **原始链接：** [GitHub官方弃用公告](https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026/)
