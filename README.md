# Startup Signal Radar

公开归档 **AI 社区与产品雷达** 每日报告。

## 目录

- [`daily/`](daily/) — 每天一份正式日报，文件名采用北京时间日期 `YYYY-MM-DD.md`。

## 同步范围

**只归档 AI 雷达正式日报。** 不同步用户消息、日常聊天、提问、系统提示、完整对话历史或非日报附件。

- 每份文件仅包含公开日报内容及必要的日期/证据链接。
- 报告中的公司声明、社区讨论、研究结果等维持原有证据边界；归档不代表重新独立验证。
- 仓库是 **Public**；禁止提交API密钥、访问令牌、私人账户信息或其他非公开内容。
- 现有ChatGPT每日任务会尝试在生成报告后提交到此仓库。如同步失败，应在任务结果中明确报告，不能声称提交成功。
- 若同日文件已存在，先核对内容，避免无提示覆盖或重复提交。
- 历史日报未被自动补全；只把已取得完整正文的报告归档。

## 报告格式

优先使用可在GitHub直接阅读的Markdown：正文、原始来源超链接、核验状态、社区信号与行动清单。原始报表如含ChatGPT专用的显示标签，入库时只清理排版标签，不更改新闻判断。
