# Startup Signal Radar Archive

用于归档 AI 社区与产品雷达的每日研究报告，以及经授权的 ChatGPT 对话历史。

## 计划目录

- `daily/YYYY-MM-DD.md` — 每日雷达报告（仅在内容已核实并完成同步后创建）
- `conversations/ai-radar-full-history.md` — 按时间顺序整理的对话历史（尚未导入）
- `conversations/ai-radar-full-history.json` — 可机读的原始消息归档（尚未导入）

## 隐私说明

此仓库当前为公开仓库。请勿直接提交未审核的私人对话、API 密钥、访问令牌或其他敏感信息。若要存放完整对话，请先确认仓库的公开范围，建议改为 Private。

## 证据要求

日报应保留原始引用链接和证据边界；区分官方自报、独立验证、社区观点与未经确认的传闻。
